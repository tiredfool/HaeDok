# 기억 01 — 보지 못한 풍경

파일: `memory-01.png`  
제작: 내장 ImageGen, 기존 화영 일반 스탠딩을 외형·화풍 참고 이미지로 사용.

## 재사용 프롬프트

16:9 가로형 미스터리 로맨스 비주얼노벨의 기억 CG. 첨부한 화영 스탠딩의 얼굴, 긴 물결 모양 갈색 머리, 아이보리 가디건, 회청색 원피스, 낡은 스케치북과 섬세한 선화·채색을 유지한다. 참고 이미지는 외형과 화풍에만 사용하고 포즈와 구도는 새로 구성한다.

카메라는 인물로부터 약 2.5m 떨어진 눈높이, 풀프레임 환산 35mm 렌즈의 미디엄 와이드 숏. 화영의 왼쪽 뒤에서 비스듬히 바라보되 오른쪽을 향한 옆얼굴과 한쪽 눈의 감정이 읽히도록 각도를 조절한다. 골반 위까지 담는다. 화영은 화면 왼쪽 1/3, 결계 너머 풍경은 오른쪽 2/3에 배치한다. 수평선은 아래쪽 1/3에 두며 카메라를 기울이지 않는다. 인물이 관객을 바라보지 않게 한다.

화영은 왼손으로 스케치북을 허리에 안고, 오른손 끝으로 화면 중앙의 투명한 결계를 조심스럽게 만진다. 시선은 결계 너머 먼 불빛을 향한다. 눈빛에는 처음 보는 곳을 기억해 낸 듯한 그리움과 조용한 놀라움이 담긴다. 입술은 살짝 벌어진다.

화영의 눈 → 결계에 닿은 손끝 → 먼 마을의 불빛 순서로 시선이 흐르게 한다. 전경 아래 모서리에는 흐릿한 풀잎, 중경에는 선명한 옆얼굴과 손, 후경에는 안개 낀 산 능선과 부서진 표지판, 작은 따뜻한 불빛들을 층층이 배치한다. 배경이 무엇인지 알아볼 수 있는 적당한 심도. 결계는 가느다란 청백색 굴절 곡면으로 표현하고 풍경을 가리지 않는다.

짙은 남색 밤, 머리카락 가장자리의 은빛 달빛, 눈동자에 약하게 비치는 따뜻한 빛. 과장된 마법 효과보다 정적인 감정과 공간의 깊이를 강조한다. 얼굴과 손은 화면 중앙 80% 안전 영역 안에 배치하고, 아래쪽 15%는 자막을 얹어도 복잡하지 않게 한다.

제외: 정면 증명사진 구도, 극단적인 광각 왜곡, 과도한 부감·앙각, 더치 앵글, 불투명한 벽, 깨진 유리 효과, 추가 인물, 부자연스러운 손가락, 분할 화면, 글자, 자막, UI, 로고, 워터마크.
